# 📊 MPScore-Daily 學生平時成績歷程與分析手札

**MPScore-Daily** 是專為國中小導師與科任教師打造的「**平時成績管理、四大分項均標結算與 L1~L6 單元成績走勢分析系統**」。
老師只需在 Google 試算表像平常一樣登記每次小考與平時成績（例如：`國習L1`、`作業卷L1`、`語詞L1`、`測驗卷L1`），無須手動拉複雜的 `AVERAGE` 公式，系統即自動算好每位學生的**四大分項平時平均、各科平時總平均、全班平均常模對比與 L1~L6 單元學習曲線**，並產生專屬 QR Code 平時成績通知小卡！

---

## 🌟 核心功能亮點

1. **📊 四大平時評量分項平均自動結算**：
   - 系統依據試算表表頭名稱，自動將各次平時分數歸納為四大核心分項：
     - **📘 習作平時成績**（如：`國習L1`、`數習L2`、`社習L3`）
     - **📝 作業卷平時成績**（如：`作業卷L1`、`學習單`、`隨堂卷`）
     - **🔤 語詞與基礎平時成績**（如：`語詞L1`、`聽寫`、`圈詞`、`計算L1`）
     - **🎯 單元測驗卷成績**（如：`測驗卷L1`、`平時考`、`單元卷`）
   - 自動計算各分項之「個人平時平均」、「班級該項平均」、「與班均差值」與「最高/最低分區間」。
2. **📈 L1 ➔ L6 單元平時成績走勢與常模對比圖**：
   - 以 Chart.js 雙線對比圖（個人平時成績實線 vs 班級平均虛線）呈現 `L1 ➔ L2 ➔ L3 ➔ L4 ➔ L5 ➔ L6` 各單元得分起伏。
   - 支援一鍵切換檢視「🌟 單元總均 / 🎯 測驗卷 / 📘 習作 / 📝 作業卷 / 🔤 語詞聽寫」。
3. **📋 單元橫向成績對照總表 & 落差診斷**：
   - 提供清晰的「單元橫向成績對照表」（列：`L1~L6`；欄：`習作、作業卷、語詞、測驗卷、該單元總均`）。
   - 自動比對「習作練習平均」與「單元測驗卷平均」之落差，並標示表現最穩健單元與考前需優先複習單元。
4. **🖨️ 教師 A4 平時成績通知小卡列印中心（雙版本 PDF）**：
   - **👨‍👩‍👧 家長發放版小卡**：A4 雙欄 10 格滿版排版，內含各科平時總均、四大分項平均摘要、專屬 QR Code 與家長簽章欄。
   - **📋 教師留存總表版**：一頁彙整全班座號、姓名、8 碼查詢代碼與各科平時總平均留底備查。

---

## 🚀 檔案架構

- [`index.html`](index.html)：教師設定精靈、全班平時成績總表、顯示模組設定與 A4 平時成績通知小卡 PDF 預覽/下載中心。
- [`parent.html`](parent.html)：家長與學生專屬平時成績歷程手札（支援四大分項平均、單元走勢圖、單元橫向成績總表與診斷建議）。
- [`config.js`](config.js)：前端全域設定檔（可填入預設 Google Apps Script Web App `API_URL`）。
- [`gas/Loader.gs`](gas/Loader.gs)：貼入 Google 試算表 Apps Script 的免維護輕量啟動器。
- [`gas/Code.gs`](gas/Code.gs)：雲端核心平時成績解析、四大分項平均計算與班級常模統計引擎。
