# 🌱 MPScore-Daily 學生平時學習歷程手札

> **核心定位：從「查分數」升級為「看見學習習慣與成長脈絡」**  
> 與 `MPScore`（期中/期末段考橫向截面分析）相輔相成，`MPScore-Daily` 專注於記錄與視覺化孩子一整個學期、每週點滴累積的**縱向形成性評量（Formative Assessment）成長歷程**。

---

## 一、 核心價值定位：從「查分數」到「看見學習習慣」

段考看的是「總結結果」，而平時成績看的是**「學習態度、作業習慣與單元弱點」**。  
將單科 20 多欄的日常登記表，透過自動分群與視覺化提煉，讓家長與學生一眼看見：
- **觀念斷層及早發現**：「原來孩子不是大考粗心，而是從第 3 課（L3）單元測驗卷就開始出現觀念斷層！」
- **日常態度正向肯定**：「習作與作業卷每一次都維持在 95 分以上，代表課堂專注度與作業態度非常棒！」
- **待補交/待訂正溫馨提醒**：將試算表中的底色標記自動轉化為溫馨提醒，免去聯絡簿反覆催繳。

---

## 二、 試算表結構設計：無痛延續老師現有的登記習慣

**設計原則：老師完全不需要改變現有的 Excel / Google 試算表打字與標色習慣！**

```text
【平時成績試算表架構】
├── 📋 學生名冊         (班級、座號、姓名、專屬代碼 Token、啟用狀態 —— 可與 MPScore 共用同一組代碼！)
├── 📘 國語平時成績     (國習 L1~L6 | 作業卷 L1~L6 | 語詞測驗 | 單元測驗卷 | 期中/期末平時平均)
├── 📐 數學平時成績     (數習 L1~L5 | L1~L5 單元測驗卷 | 期中/期末平時平均)
├── 🌍 社會平時成績     (社習/習作 | 單元測驗卷 | 期中/期末平時平均)
├── 🔬 自然/英文平時成績 (可自由擴充任意學科分頁)
└── 📊 期末平時成績總表 (國語總均、數學總均、社會總均、各細項平均、資源班調整分數)
```

### 💡 後端 Apps Script (`gas/Code.gs`) 自動解析機制
1. **多重欄位關鍵字自動分群（四大支柱）**：
   - 包含 **`習`**（如：國習 L1、數習 L1、習作）➔ 自動歸類為 **【課堂習作表現】**
   - 包含 **`作業卷 / 練習卷 / 作業`** ➔ 自動歸類為 **【課後作業卷】**
   - 包含 **`語詞 / 聽寫 / 圈詞 / 生字`** ➔ 自動歸類為 **【語詞基礎聽寫】**
   - 包含 **`測驗 / 考卷 / 小考 / 單元卷`** ➔ 自動歸類為 **【單元測驗小考】**
2. **儲存格底色標記自動轉化（`getBackgrounds()`）**：
   - **黃色底色標記**（缺繳 / 待補測）➔ 自動轉為前台友善標籤：`⏳ 待補交 / 待補測`
   - **粉紅色底色標記**（及格邊緣 / 待訂正 / 需加強）➔ 自動轉為前台溫馨引導：`🌱 需重點複習`

## 三、 家長手機端視覺呈現設計（四大模組）

延續**「暖陽澄金、萌芽生機、溫潤暖米（`#FAF8F5`）」**正向教育風格，規劃以下 4 個視覺層次：

```text
+--------------------------------------------------+
|  🌱 605 班 學生平時學習成長手札                   |
|  陳小華 (座號 02)   [114學年度第1學期]            |
+--------------------------------------------------+
|  【主科平時狀態摘要卡 (毛玻璃浮島)】             |
|  📘 國語 94.5 分   📐 數學 87.7 分   🌍 社會 83.5 分 |
+--------------------------------------------------+
|  [📘 國語]   [📐 數學]   [🌍 社會]  <-- 科目頁籤  |
+--------------------------------------------------+
|  📊 學習指標四大支柱 (四向分群評量卡)            |
|  • 課堂習作表現：97.2 分 (認真扎實 ⭐)            |
|  • 課後作業卷  ：99.0 分 (表現卓越 🌟)            |
|  • 語詞基礎聽寫：89.0 分 (穩步精進 🌿)            |
|  • 單元測驗小考：89.0 分 (觀念良好 💪)            |
+--------------------------------------------------+
|  📈 單元學習歷程脈絡折線圖 (Sparkline Timeline)  |
|  [L1] ─── [L2] ─── [L3] ─── [L4] ─── [L5] ─── [L6]|
|   98分    100分    74分     78分     94分    96分 |
|                     ▲ 發現弱點單元 (建議及早補強) |
+--------------------------------------------------+
|  ⏳ 待補交 / 待補測溫馨提醒箱                     |
|  📋 本學期各次平時作業與測驗明細展開清單         |
|  💡 親師同心叮嚀                                 |
+--------------------------------------------------+
```

1. **頂部「主科平時表現摘要卡」**：一眼掌握國、數、社等科目目前累積的平時總平均。
2. **「學習四大支柱」分群評量卡**：將數十個小分數自動濃縮為「課堂習作、課後作業、語詞基礎、單元小考」四大指標，協助家長分辨孩子是「作業態度好但考試易緊張」還是「測驗表現佳但習作常漏交」。
3. **單元時序折線圖（Sparkline Timeline）**：橫軸依單元（L1 ➔ L2 ➔ L3 ➔ L4 ➔ L5 ➔ L6...）展開，直觀標示吸收最佳與遇到瓶頸的單元。
4. **待補交/補測溫馨提醒箱 & 明細清單**：自動汇总試算表中的黃色/粉紅色標記格，讓家長在家能溫馨陪伴孩子補齊進度。

## 四、 與 MPScore 段考系統的雙軌協同

| 比較維度 | 🌱 `MPScore-Daily`（本專案） | 📊 `MPScore`（段考分析系統） |
| :--- | :--- | :--- |
| **核心焦點** | 平時學習習慣、單元吸收脈絡、作業缺交追蹤 | 期中/期末定期評量、班級分佈常模、跨次進退步 |
| **更新頻率** | **高頻率**（每週或每單元隨堂更新） | **低頻率**（每學期 2～3 次定期評量） |
| **專屬代碼 (Token)** | **可 100% 互通共用**（同一組 6 碼代碼） | **可 100% 互通共用** |
| **通知小卡匯出** | A4 PDF 預覽與雙版本下載（家長版 / 教師留存版） | A4 PDF 預覽與雙版本下載（家長版 / 教師留存版） |
