# 📊 MPScore-Daily 學生平時成績歷程與分析手札

**MPScore-Daily** 是專為國中小導師與科任教師打造的「**平時成績管理、分項均標自動結算與學習曲線分析系統**」。
老師只需在 Google 試算表像平常一樣登記每次小考與平時成績（例如：`國習L1`、`作業卷L1`、`語詞L1`、`測驗卷L1`），無須手動拉複雜的 `AVERAGE` 公式，系統即自動算好每位學生的**分項平時平均、各科平時總平均、全班平均常模對比與每次評量學習曲線**，並產生專屬 QR Code 平時成績通知小卡！

- **網站作者 / 系統規劃**：楊家驊老師 (Chiahua Yang)

---

## 🌟 核心功能亮點

1. **📊 動態平時評量分項平均結算 & 作業/考試雙軌標章**：
   - 系統依據試算表表頭名稱與第 3 列「評量性質（作業 / 考試）」，自動將各次平時分數歸納為該科目實際存在的分項類別（如：**📘 習作平時成績**、**📝 作業卷平時成績**、**🔤 語詞與基礎平時**、**🎯 單元測驗卷成績**），試算表未出現的分項絕不顯示空白卡片。
   - 自動計算各分項之「個人平時平均」、「班級該項平均」、「與班均差值（附無障礙方向符號 `▲/▼/＝`）」与「最高/最低分區間」。
   - 分數視覺量尺同時標示「**長方形色條為當事學生成績**」與「**立體圓形綠點 ●▲ 為班級平均**」，直覺好讀。
2. **📈 每次評量得分走勢與班級常模對比圖**：
   - 以 Chart.js 雙線對比圖（個人平時成績實線 vs 班級平均虛線）完整呈現試算表每一次平時評量的真實得分軌跡。
   - 支援一鍵切換檢視「🌟 全部項目 / 📝 作業 / 🎯 考試 / 各分項類別」。
3. **🗂️ 雙模式平時成績明細（卡片明細 / 列表總表）**：
   - 預設採用手機最易讀的「**🗂️ 卡片明細**」檢視每次平時分數，並支援一鍵切換「**📋 列表總表**」及依分項篩選。
4. **🛡️ 個資法保護與專屬 QR Code 免輸入登入**：
   - **姓名去識別化**：家長端自動將學生姓名中間字元遮罩為圈圈（三字姓名如 `王○明`、兩字姓名如 `王○`），兼顧個資保護與辨識度。
   - **純 QR Code 驗證**：移除手動輸入代碼框，家長可透過紙本通知小卡掃描 QR Code、開啟頁面內建鏡頭掃描，或直接從手機相簿上傳 QR Code 截圖/照片即刻登入。
5. **🖨️ 教師 A4 平時成績通知小卡列印中心（雙版本 PDF ‧ 全欄位可自訂）**：
   - **👨‍👩‍👧 家長發放版小卡**：A4 雙欄 10 格滿版排版，**小卡紙本不印出具體成績數字（保障學生隱私）且免家長簽名回條**，改以「兩步驟掃碼登入與隨時查看指南」搭配專屬 QR Code。
   - **✏️ 9 大文字區塊全面開放教師自訂**：小卡頂部標題、右上角期別標籤、學生資訊列右側提示、追蹤橫幅文字、區塊一＆二之標題與內文、底部溫馨叮嚀、QR Code 下方提示字皆可由教師自由修改並自動記憶於瀏覽器。
   - **📋 教師留存總表版**：一頁彙整全班座號、姓名、查詢代碼、專屬連結狀態與登入追蹤說明留底備查。
6. **🎨 米藍與米綠相間視覺設計 ＆ Apple HIG / Apple Design 標準**：
   - 全站採用溫潤護眼的**米藍色 (`#EAF4FB`) 與米綠色 (`#EAF6F0`) 相間**卡片設計。
   - 符合 **Apple Human Interface Guidelines (HIG)** 與 **Apple Design** 規範：全站最小字級 `>= 12px`、光學字距與等寬數字對齊 (`tabular-nums`)、觸控目標 `>= 36px~44px`、WCAG AA 對比度、色覺辨識無障礙方向符號 (`▲/▼/＝`)、毛玻璃導覽列 (`backdrop-filter`)、按壓微回彈物理回饋，以及 `prefers-reduced-motion` / `prefers-reduced-transparency` / `prefers-contrast` 系統輔助使用支援。

## 🚀 檔案架構

- [`index.html`](index.html)：教師端設定精靈、全班平時成績總表、家長端顯示模組開關、小卡全欄位文字自訂與 A4 平時成績通知小卡 PDF 預覽/下載中心。
- [`parent.html`](parent.html)：家長與學生專屬平時成績歷程手札（支援 QR Code 相機/相簿掃描、姓名去識別化、分項平均量尺、走勢圖與雙模式得分明細）。
- [`config.js`](config.js)：前端全域設定檔（可填入預設 Google Apps Script Web App `API_URL`）。
- [`gas/Loader.gs`](gas/Loader.gs)：貼入 Google 試算表 Apps Script 的免維護輕量熱更新啟動器。
- [`gas/Code.gs`](gas/Code.gs)：雲端核心平時成績解析、作業/考試雙軌統計、分項平均計算與班級常模引擎。
