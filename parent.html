點擊展開查看：考卷難易度指數（P* 方法三抗極端值校正）、分項平均、常模差值與走勢內插公式

展開計算方式說明 ▼ 收起說明 ▲
1. 考卷難易度指數（Difficulty Index, P*，方法三抗極端值校正） 試卷難易度評估
  • 基本得分率：平均得分率 P_mean = X̄ / 100，中位數得分率 P_med = Median / 100（排除請假與缺考樣本）。
  • 抗極端值偏態校正：當班級分數出現偏態（|X̄ − Median| > 3）時，自動啟用抗極端值加權：
    P* = 0.6 × P_mean + 0.4 × P_med
    （若 |X̄ − Median| ≤ 3 分佈對稱，則 P* = P_mean，換算百分制指數為 P* × 100）。
  • 分級標準：≥ 80 分 🟢 偏易、65 ~ 79.9 分 🎯 適中、50 ~ 64.9 分 🔥 偏難、< 50 分 ⚡ 極具挑戰。
*難易度以班級成績估計。
2. 平時分項平均與請假免計分算術平均法 分項與總均結算
  • 動態分項歸納：依試算表評量性質（📝 作業 / 🎯 考試）與欄位名稱，自動歸納為「📘 習作」、「📝 作業卷」、「🔤 語詞/基礎」、「🎯 單元測驗卷」，計算算術平均 X̄ = (∑x_i) / n。
  • 公、事、病、喪請假免計分：成績格登記為公假、事假、病假、喪假時，依法免計分，自動從個人與班級平均之計算分母 n 中排除，絕不當作 0 分拉低平均。
3. 班級常模相對差值與百分等級（PR 值）推估 常模落點分析
  • 與班均差值：Diff = 個人得分 − 班級該項平均，並搭配色覺無障礙符號（▲ 高於班均、▼ 低於班均、＝ 與班均持平）。
  • 量尺視覺對位：分項卡片中「長方形色條」代表學生個人平均，「立體圓點（●▲）」代表班級該項平均，直覺對比相對位置。
4. 學習走勢圖請假節點線性內插法（Linear Interpolation） 視覺連續性演算法
  • 折線平滑過渡：當某次評量為請假免計分時，為避免折線斷裂或誤繪為 0 分，圖表座標以相鄰前後有效評量分數進行線性內插：Y = S_prev + [(i − i_prev)/(i_next − i_prev)] × (S_next − S_prev)。
  • 嚴格標記免計：內插值僅供維持折線視覺連貫與點擊定位，提示框與卡片均嚴格顯示假別（如 💊 病假（請假不計分））。
