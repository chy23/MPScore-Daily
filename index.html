                            1. 試卷難易度評估（Test Difficulty Index, P*）
                            方法三：抗極端值校正
                        

                        

                            為避免單一極端低分或高分扭曲全班試卷難度判斷，系統同時計算班級有效成績之平均得分率與中位數得分率：
                        

                        

                            
• 平均得分率：P_mean = X̄ / 100（X̄ 為班級算術平均數）

                            
• 中位數得分率：P_med = Median / 100（Median 為班級中位數）

                            
• 偏態檢定與抗極端值加權：

                            

                                - 當 |X̄ - Median| > 3（遇偏態）時：

                                  P* = 0.6 × P_mean + 0.4 × P_med

                                - 當 |X̄ - Median| ≤ 3（常態分佈）時：

                                  P* = P_mean
                            

                        

                        

                            
📊 難易度四級標準（依 P* × 100 百分制換算）：

                            

                                ≥ 80 分：🟢 偏易
                                65 ~ 79.9 分：🎯 適中
                                50 ~ 64.9 分：🔥 偏難
                                < 50 分：⚡ 極具挑戰
                            

                            
*難易度以班級成績估計。

                        

                    


                    
                    

                        

                            
2. 個人分項平均、各科總均與請假免計分機制

                            

                                採用算術平均數（Arithmetic Mean）：X̄ = (∑ 有效得分) / N_有效。凡登記為「公假、事假、病假、喪假」之項目依法免計分，不以 0 分計算，亦不納入個人與班級平均之除數分母（N_有效）。
                            

                        


                        

                            
3. 班級常模對比差值（Δ）與百分等級（PR 值）

                            

                                • 班均差值：Δ = 個人得分 - 班級平均 X̄，正值代表高於班級常模。

                                • 百分等級（PR）：依學生個人總均於全班有效總均分佈中之相對位置換算（PR99 代表領先全班 99% 同儕，僅供內部學習定位參考）。
                            

                        


                        

                            
4. 學習走勢圖之請假點視覺線性插補法

                            

                                為維持學習曲線連續性，折線圖遇請假項目時採用前後有效評量線性插補（Linear Interpolation）繪製過渡軌跡點並標示假別徽章；該插補值僅供圖表視覺連線，絕不計入任何實際平均分數。
